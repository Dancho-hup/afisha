# Анализ лояльности пользователей Яндекс Афиши

Учебный проект: исследование факторов, связанных с возвратом пользователей
(повторными покупками билетов) на платформе Яндекс Афиша по данным 2024 года.

## Структура

| Файл | Назначение |
|---|---|
| `afisha_project.ipynb` | Тетрадка с SQL-выгрузкой, предобработкой, анализом и выводами |
| `requirements.txt` | Зафиксированные версии библиотек |
| `.env.example` | Шаблон переменных окружения для подключения к базе |
| `.gitignore` | Исключает `.env`, виртуальное окружение, чекпоинты Jupyter и данные |

## Запуск

1. Клонировать репозиторий и перейти в папку проекта.
2. Создать виртуальное окружение и установить зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate        # Windows
   # source .venv/bin/activate   # macOS / Linux
   pip install -r requirements.txt
   ```

3. Создать файл `.env` по образцу `.env.example` и заполнить параметры
   подключения к PostgreSQL (`DB_USER`, `DB_PASSWORD`, `DB_HOST`, `DB_PORT`, `DB_NAME`).
4. Открыть `afisha_project.ipynb` в Jupyter или VS Code и выполнить ячейки сверху вниз.

Данные выгружаются из базы напрямую SQL-запросом, локальные файлы с данными не требуются.

## Этапы анализа

1. Загрузка данных SQL-запросом и предобработка: приведение выручки к рублям,
   фильтрация некорректных значений и выбросов, пересчёт интервалов между заказами.
2. Построение профиля пользователя (одна строка на пользователя).
3. Исследовательский анализ: распределение числа заказов, признаки первого заказа,
   средняя выручка и число билетов, день недели, интервалы между покупками.
4. Корреляционный анализ (phi_k).
5. Общий вывод и рекомендации.
